The small model syntax

It breaks up a small model: one that does a single job and answers with a number, a choice, a span or codes, never with sentences, and leaves the decision to code. It has 6 element types and 36 elements, and a small model described in it is one choice of elements from each type.

Instances

  • the small model builder: choose one element of each type and read what the nearest models already built were measured to do

Element types and elements

job holds one essential

The one operation the model does. A larger task is broken into such operations first, each done by its own model or by code.

sort
puts each thing it reads into one of a few kinds set in advance
point
finds the part of what it reads that answers a question, or says there is none
match
says which item on a list written in advance the thing it reads goes with
spot
says which of a set of words or sounds recorded in advance occurred
score
gives each option a number, and code takes the highest
choose
picks codes from sets, one slot at a time

reads holds one essential

What goes into the model each time it answers.

a sentence
one sentence at a time
a pair of sentences
two sentences read together, such as a question and its answer
a passage
a few sentences up to a page, with a question about it
a whole text
a whole text, shortened to fit the model's window
a window of sound
a second or two of sound from a microphone
numbers
a few whole numbers that describe a situation
codes
numbers that stand for words, never the words themselves

answers holds one essential

The shape of what comes out. Every answer can also be none, and code reads none as don’t know.

a kind
one of a few kinds set in advance
yes or no
one of two answers
a span
where an answer starts and ends in what it read
an item
one item from a list written in advance
a number
a number for each option, which code compares
codes
codes chosen from sets, which code turns back into words

base holds one essential

The model it starts from before it is trained on the job.

a MiniLM reader taught to point
a 33-million-parameter English encoder already trained to find answers in text
a MiniLM encoder with a new head
the same size of encoder with a small new layer that picks one of a few kinds
an adapter on a trained reader
a small set of added weights trained on top of a model already trained for a nearby job
a multilingual small encoder
a small encoder that reads several languages, retrained on Indian languages
an audio encoder, frozen
a model trained on sound, kept as it is, with a small scorer trained on top
a keyword-spotting encoder
a tiny encoder, tens to hundreds of thousands of parameters, that compares sound with recorded examples
trained from scratch
no ready model: every weight learnt from the start
a few whole-number weights
no neural network: a handful of numbers that multiply the inputs

labels holds one essential

Where the right answers it learns from come from.

the maker's keys
the maker's own answers, keyed one item at a time on blind sheets
a stated rule
answers code works out from a rule the maker stated in words
written rows
rows written for training by another model, with the answer known from how each was made
another model's reading
labels another model gave, used on the maker's word
a dataset's labels
the labels a public dataset came with

runs on holds one essential

Where the model answers once it is trained.

a Raspberry Pi 5
inside a toy or a game, on its processor, with nothing sent anywhere
a phone's browser
in the page itself, with nothing sent to a server
a small server
a server's processor with no graphics card, such as one with 1 CPU and 2 GB
a graphics card
a machine with a graphics card, such as an RTX 3060 with 12 GB

Left out

A model that writes. Anything that writes sentences for people is not a small model in this syntax: a small model answers with a kind, a span, an item, a number or codes, and code decides what follows. Also left out: what the model is for in the world, its name, and the keys, which stay with the person who keyed them.
