The small model builder

Choose what a small model does, what it reads, what it answers, what it starts from, whose labels it learns from and where it runs. The builder shows the models I have already built that come nearest to those choices, with what each was measured to do and on which test. It does not predict a figure for a model that does not exist yet.

The figures are copied from my own records of each model as they were measured. Each model I measure from now on is added here. The syntax itself: the small model syntax.
